# mse-2025-rocket1


## Установка и запуск
Здесь описывается процесс установки и запуска релизной версии. Для запуска версии в разработке перейдите к [следующему разделу](#установка-и-запуск-версии-в-разработке)

### Зависимости
Для функционирования  программного продукта необходимо наличие на машине установленного ПО Docker актуальной версии 

### Процесс запуска
Для установки и запуска необходимо:

1. Проверить наличие зависимостей из [соответствующего раздела](#зависимости)
2. Склонировать репозиторий 
```
    git clone https://github.com/moevm/mse1h2025-rocket1
```
3. Перейти в директорию deployment
```
cd mse1h2025-rocket1/deployment
```
4. Запустить dockeр-compose релизной версии
``` 
docker compose -f prod/docker-compose.yaml up -d
```

### Остановка
Для прекращения работы программного продукта требуется

1. Перейти в директорию deployment
```
cd mse1h2025-rocket1/deployment
```
2. Отдать dockeр-compose релизной версии команду об остановке
``` 
docker compose -f prod/docker-compose.yaml down
```

## Установка и запуск версии "в разработке"
Здесь описывается процесс установки и запуска релизной версии. Для запуска версии в разработке перейдите к следующему разделу

### Зависимости версии "в разработке"
Для функционирования  программного продукта необходимо наличие на машине установленного ПО Docker актуальной версии, а также следующих программ:
```
python >= 3.13
uv
bun
```

### Процесс запуска
Для установки и запуска необходимо:

1. Проверить наличие зависимостей из [соответствующего раздела](#зависимости-версии-в-разработке)
2. Склонировать репозиторий 
```
    git clone https://github.com/moevm/mse1h2025-rocket1
```
3. Перейти на ветку ```development```
```
git checkout development
```
4. Перейти в директорию deployment
```
cd mse1h2025-rocket1/deployment
```
5. Запустить dockeр-compose версии в разработке
``` 
docker compose -f prod/docker-compose.yaml up -d
```
6. Перейти в директорию backend
```
cd ../backend
```
7. Запустить бэкенд-сервер
```
uv run fastapi dev
```
8. Перейти в директорию frontend
```
cd ../frontend
```
9. Установить зависимости фронтенд-сервера
```
bun install
```
10. Запустить фронтенд-сервер
```
bun run dev
```
